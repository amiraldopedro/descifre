Conectar o painel ao GitHub

Os botões do painel mandam o GitHub fazer o trabalho: agendar, salvar o SEO e pedir ajustes. Para isso, este navegador precisa de uma chave do GitHub. Ela fica guardada só aqui, no seu navegador.

  1. Abra github.com/settings/personal-access-tokens/new
  2. Em Repository access, escolha Only select repositories → descifre
  3. Em Permissions, dê Actions: Read and write e Contents: Read-only
  4. Gere a chave, copie e cole abaixo
